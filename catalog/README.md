# Content catalog

[`thesauri.json`](thesauri.json) is the machine-readable catalog for this release. Each entry has a stable package ID, BCP 47 locale, display names, format, source version, tag, license, upstream provenance, and a single asset with an exact byte count and SHA-256.

Use the URL pinned to the release tag. Verify both `bytes` and `sha256` before accepting a download. Preserve the license and notice links when redistributing an asset. The `date` field is null if the upstream notice does not provide a date.

The catalog describes public content. It does not define an app API, and does not contain the application's source or private configuration.
