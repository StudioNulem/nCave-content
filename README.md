# nCave-content

Publicly distributable content for [nCave](https://ncave.pages.dev/), an Android writing app by Studio Nulem. The application source code is maintained separately and is private.

The first release, [`content-2026.11.1`](https://github.com/StudioNulem/nCave-content/releases/tag/content-2026.11.1), provides German, French, Polish and Slovak MyThes thesauri. Get the data from the release assets. The [catalog](catalog/thesauri.json) lists versioned download URLs, byte sizes and SHA-256 checksums.

Each package has its own [license and notices](licenses/README.md). The [corresponding-source directory](corresponding-source/README.md) records where the data came from and how to reproduce the two derived files.

This repository may also distribute spelling dictionaries, nCave templates (`.nct`), warmups and other content in the future.
